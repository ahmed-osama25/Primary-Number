# Prime Number Checker 🔢

A simple **C++ console application** for checking prime numbers and displaying all prime numbers within a given range.

## 📌 Features

* Check whether a number is a prime number.
* Display all prime numbers from `2` up to a given limit.
* Interactive menu.
* Continuously runs until the user chooses to exit.
* Clears the console after each operation.
* Built using **Object-Oriented Programming (OOP)** concepts.

## 🛠️ Technologies

* C++
* Object-Oriented Programming (OOP)
* Console Application

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/Prime-Number.git
```

2. Open the project in your C++ IDE.

3. Compile and run `Primary Number.cpp`.

## 🖥️ Example

```text
===== Prime Number Checker =====
1- Check Prime Number
2- Show Prime Numbers
3- Exit

1
Enter A Number: 17
17 is a prime number.

Press any key to continue . . .
```

For option `2`:

```text
===== Prime Number Checker =====
```
